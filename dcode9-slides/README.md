# Dcode9 / Slides

Central repository and workspace for slide decks, interactive diorama presentations, and generative presentation engines hosted at [slides.d-verse.in](https://slides.d-verse.in).

## Structure
- `/english-x-sigma`: Glimpses of India — Goa & Sikkim (CBSE Class X Sigma diorama)
- `/sciencev2`: Improvement in Food Resources
- `/smvs`: World Cup 2026
- `/yoga`: Entrepreneurial Skills
- `/frenchv2`: Présentation de Français · Les Temps et La Conjugaison
- `/slidecraft`: SlideCraft CLI & schema presentation compiler
- `/assets`: Shared assets, photography, and poster exports
